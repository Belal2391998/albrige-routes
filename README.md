# Albridge Smart Routes

قم ببناء تطبيق ويب تفاعلي واحترافي لشبكة النقل والمواصلات باللغة العربية بالكامل (RTL) لصالح "شركة البريدج Albridge - شبكة خطوط النقل الذكية" باستخدام React، Tailwind CSS، Framer Motion، Lucide Icons، وخرائط Leaflet.

---

### 🎨 الهوية البصرية وتجربة المستخدم (UI/UX)

- **الاتجاه:** واجهة عربية كاملة من اليمين إلى اليسار (`dir="rtl"`, خط Cairo أو Tajawal).

- **لوحة الألوان:** كحلي ملكي داكن (`#0B2265`)، ذهبي متوهج (`#E5A93C`)، أسود فحمي (`#0F172A`)، وخلفيات رمادية فاتحة (`#F8FAFC`).

- **التصميم:** تأثيرات زجاجية عصرية (Glassmorphism)، أنيميشن سلس جداً، وتصميم نظيف وخالٍ من أي عناصر مبعثرة.

---

### 🧭 نظام التنقل والهيدر الذكي (Navigation & Header Architecture)

- **تنظيم صفحات الخطوط في الهيدر (Clean Dropdown / Drawer Menu):**

  - لا يتم رص أسماء الخطوط الأربعة بشكل عشوائي أو مباشر في شريط الهيدر.

  - يتم تضمين زر تنقل رئيسي وأنيق بعنوان **"خطوط النقل"** مزود بأيقونة سهم ومؤشر بصري.

  - عند النقر أو التمرير فوق الزر، تفتح قائمة منسدلة زجاجية أنيقة (Glassmorphic Dropdown) أو شريط جانبي انزلاقي (Slide-over Drawer) يعرض الخطوط الأربعة بشكل منظم ومرتب مع أيقونة ولون مخصص لكل خط.

  - يحتوي الهيدر أيضاً على شعار Albridge، زر البحث، ومبدل الوضع الليلي فقط.

---

### 🏠 1. الصفحة الرئيسية (`/`): واجهة استعراضية حصرية (Showcase Only)

- **طبيعة الصفحة:** واجهة عرض احترافية للتعريف بالشبكة فقط، **دون عرض محطات أو تفاصيل مسارات الخطوط بداخلها**.

- **مكونات الصفحة الرئيسية:**

  - **قسم الاستعراض الرئيسي (Hero Showcase):** سلايدر تفاعلي أو خلفية متحركة تعرض أسطول حافلات Albridge مع عبارات ترحيبية وشعار الشركة: "شبكة خطوط النقل الذكية - دقة في المواعيد وراحة في التنقل".

  - **قسم المزايا التنافسية (Features Grid):** بطاقات تعريفية بخدمات الشركة (تتبع المسارات الذكي، دقة التوجيه عبر خرائط Google، الأمان، الراحة).

  - **قسم المعاينة البصرية والأسطول (Fleet & Service Showcase):** معرض صور تفاعلي بتقنية Carousel للتعريف بجودة خدمات النقل.

  - **زر توجيه رئيسي (CTA):** "استكشف خطوط النقل ومحطات التجمع" يفتح قائمة الخطوط فوراً لنقل المستخدم إلى الصفحة الخاصة بالخط المطلوب.

---

### 🌟 الميزات التفاعلية وأنيميشن المسارات (داخل صفحات الخطوط المستقلة)

1. **صفحة مستقلة لكل خط منفصل تماماً:**

   - كل خط له صفحته ورابطه الخاص (`/lines/line-1`، `/lines/line-2`، إلخ).

2. **شريط المسار التفاعلي وأنيميشن حركة الحافلة:**

   - جدول زمني تفاعلي يربط كافة نقاط التجمع بمسار متصل.

   - أيقونة حافلة تتحرك بنعومة فائقة لتستقر عند المحطة المحددة.

   - المسار خلف الحافلة يضيء بتدرج ذهبي وأزرق متوهج، بينما تظل المحطات القادمة بلون خافت.

   - إمكانية التنقل بين المحطات بسلاسة عبر السحب باللمس (Swipe) أو أزرار التحكم (السابق / التالي) أو النقر المباشر.

   - نبض رادار (Radar Pulse) عند كل محطة نشطة مع فتح بطاقة تفاصيلها بحركة زنبركية.

3. **شاشة المعاينة البصرية للمحطة قبل التوجيه (Visual Landmark Preview Modal):**

   - عند اختيار أو النقر على أي محطة، تفتح نافذة منبثقة أنيقة تعرض:

     - صورة واضحة لنقطة التجمع لتسهيل التعرف عليها بصرياً عند الوصول.

     - اسم نقطة التجمع الدقيق ووصف المعلم المحيط.

     - خريطة تفاعلية مصغرة مدمجة للموقع.

     - زر رئيسي متوهج: `🗺️ الانتقال إلى الموقع عبر خرائط Google` لفتح الملاحة وتطبيق الخرائط مباشرة عبر إحداثيات GPS (`https://www.google.com/maps/search/?api=1&query=LAT,LNG`).

4. **ميزة "أقرب نقطة تجمع لموقعي" عبر الـ GPS:**

   - زر مدمج في كل خط لحساب المسافة وتحديد أقرب نقطة تجمع للمستخدم على ذلك الخط فوراً.

  ```typescript

  export interface Stop {

    id: string;

    name: string;

    lineId: number;

    order: number;

    lat: number;

    lng: number;

    imageUrl: string;

    landmarkDescription: string;

    googleMapsUrl: string;

  }

  export interface Line {

    id: number;

    slug: string;

    title: string;

    subtitle: string;

    badge: string;

    color: string;

    stops: Stop[];

  }

## Development

You need Node.js and npm.

```sh
git clone https://github.com/Belal2391998/albrige-routes.git
cd albrige-routes
npm i
npm run dev
```

Build for production:

```sh
npm run build
```

Deployed on Vercel from the `main` branch.
